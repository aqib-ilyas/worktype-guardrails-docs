# worktype-guardrails-docs (archived)

The documentation for **Work Type Guardrails for Jira** has moved to
dripwork.dev and is maintained there:

- App overview: <https://dripwork.dev/app/worktype-guardrails/>
- Documentation: <https://dripwork.dev/app/worktype-guardrails/docs/>
- Privacy policy: <https://dripwork.dev/app/worktype-guardrails/privacy/>
- Marketplace listing: <https://marketplace.atlassian.com/apps/48063553>

This repository only serves redirect pages so existing links keep working.
GitHub Pages cannot issue a real 301, so each page uses a canonical link, an
instant meta refresh and a JavaScript fallback. `.nojekyll` keeps Pages from
rebuilding the old Markdown over them.

Do not add content here. Edit the pages on dripwork.dev instead.
